# 诗笺

一个离线运行的古诗文查询、笺注阅读与导出桌面应用。界面使用 pywebview（Windows 下为 WebView2）承载，数据来自项目内的 SQLite 数据库，不依赖网络。

## 功能

- **按标题检索**：输入标题片段即可查询，例如「屈原」可找到《屈原列传》。结果按精确匹配、前缀匹配、长度排序。
- **三种阅读模式**：原文 / 原文 · 译文 / 全文 · 笺注。
- **行内笺注**：自动识别注释词条，在正文对应位置插入上标，并给匹配词条加虚线；悬停词条或上标显示可选中复制的注释悬浮框，点击词条或上标定位到段末注释，点击注释回到正文。
- **标题改名与导航**：左上角图标返回首页并清空搜索；图标右侧在首页显示「诗笺」，搜索时显示「搜索——N条结果」，阅读页显示诗词标题。
- **题注**：注释词条命中标题（如词牌名）时，标在标题上并在文首展示。
- **宽松容错**：无法在正文中定位的注释不再拒绝阅读，会转入文末「附注」，正文仍可正常阅读。
- **界面自定义**：
  - 预设主题：宣纸、靛蓝（现代蓝）、青瓷、暖沙；
  - 自定义主色、页面背景、卡片颜色、正文颜色；
  - 自定义内容宽度百分比；
  - 分别设置原文、译文、注释的字体与字号；
  - 设置保存在本机，并同步用于 PDF 导出。
- **导出文本**：阅读版（行内上标，段末集中注释）与标准版（标题/原文/译文/注释分节）两种。
- **导出 PDF**：按当前主题、字体、字号与内容宽度排版，带页眉页脚页码。
- **界面**：圆角、纸感背景、大字号阅读排版、检索后自动收起大标题。

## 运行环境

- Windows 10/11
- Python 3.10+
- Microsoft Edge WebView2 Runtime（Windows 11 通常已自带；Windows 10 如缺失可从微软官网安装）
- Python 依赖：

python -m pip install -r requirements.txt
~~~

~~~powershell
python app.pyw
~~~

## 数据

- 数据库：assets/poetry.db
- 表：poems(title, author, dynasty, content, translation, annotation)
- 当前数据量：10,155 篇，标题索引 idx_poems_title。

## 注释解析规则

数据源中的注释并不完全规整，解析器采用保守但不再拒绝阅读的策略：

1. 逐行识别「词条：释义」，支持一行多条注释、序号前缀（如（19）、27.、⑴）、拼音括注（如「属（zhǔ）」「属(zhǔ)」）。
2. 词条内部可以带逗号，例如「纵一苇之所如，凌万顷之茫然：……」会作为一个完整词条匹配。
3. 按注释原始顺序做单调定位：优先从上一条之后寻找；若某条注释突然跳到很远、而紧随其后的注释落在前面，则将该条视为游离命中，不推进游标，避免带偏后续注释。
4. 无法在正文/标题中定位的注释会转入「附注」，不再禁止完整笺注视图。
5. 整体性说明（如「选自……」「此句……」）没有明确词条，进入「附注」，不强行插入上标。
6. 同一词条重复出现时只保留首个位置。

### 译文段落对齐

- 原文与译文段数相同时，逐段对应。
- 原文只有一段时，整段译文放在原文之后。
- 多段散文中夹有楚辞体韵文（含「兮」的段落）时，先排除韵文，再对散文与译文做保序对齐；对齐置信度不足时退回整篇译文。
- 跨韵文的长译文按句子相似度拆回前后两段原文。
- 其余段数不一致的情况，按「原文块 + 译文块」显示，不强行错配。

## 导出

导出目录固定为项目根目录下的 output/（打包后为可执行文件旁的 output/）。

### 文本

点击「导出 TXT」可选择：

- **阅读版**：与阅读页一致，两格缩进，原文带 Unicode 上标，译文随后，本段注释集中成一行。示例：

~~~text
　　屈原者，名平，楚之同姓¹也。为楚怀王²左徒³。……
　　屈原，名字叫平，是楚王的同姓。……
　　¹楚之同姓：……²楚怀王：……³左徒：……
~~~

- **标准版**：标题、朝代、作者，以及【原文】【译文】【注释】分节。

文件保存为 output/{标题}.txt，UTF-8 with BOM。同名文件会覆盖。

### PDF

点击「导出 PDF」可选择仅原文 / 原文 · 译文 / 全文 · 笺注。PDF 会使用当前主题色、原文/译文/注释字体与字号、内容宽度百分比，并保留页眉页脚与页码。勾选「不铺页面背景」可生成白底 PDF，适合打印、节省墨水。

PDF 字体优先使用系统字体：华文宋体（STSong）、华文楷体（STKaiti）、等线（DengXian）、华文仿宋（STFangsong）；缺失时回退到宋体、黑体或 Noto Serif SC。

## 界面设置

点击右上角齿轮按钮：

- **主题**：宣纸、靛蓝、青瓷、暖沙；也可用四个颜色输入自定义主色、背景、卡片、正文颜色。应用图标与左上角印章保留固定的朱砂色。
- **版式**：内容宽度 50%—96%。
- **字体与字号**：原文、译文、注释可分别选择宋体/楷体/仿宋/黑体/等线，并分别调整字号。

设置写入项目根目录的 config/config.json（打包后位于可执行文件旁），下次启动自动恢复；WebView 的 localStorage 只作临时缓存，清缓存不会丢配置。

## 设计说明

- **失败不拒绝阅读**：无法定位的注释进入「附注」，正文和译文始终可读，避免一条脏注释挡住整篇。
- **不强行错配译文**：译文分段不可靠时宁可整篇呈现，也不把一段译文硬塞到错误的原文段落；只有楚辞体韵文这种可识别结构才做启发式对齐。
- **字体大小**：正文约 19.5px，译文约 16.5px，笺注约 14.5px；可在设置中调整。PDF 正文约 12.5pt，笺注约 9.2pt。
